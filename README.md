# Spam Mail Prediction

## Project Overview

This is a Machine Learning project that predicts whether an email is **Spam** or **Not Spam**.

The project uses Natural Language Processing (NLP) and Machine Learning techniques to classify email messages.

## Objectives

- To classify emails as Spam or Not Spam.
- To preprocess and clean email text.
- To convert text into numerical features.
- To train a Machine Learning classification model.
- To evaluate the performance of the model.

## Technologies Used

- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- Machine Learning

## Project Workflow

1. Load the email dataset.
2. Clean and preprocess the text data.
3. Convert text into numerical features.
4. Split the dataset into training and testing data.
5. Train the Machine Learning model.
6. Test the model.
7. Evaluate the prediction results.

## Project Files

- `Spam_Mail_Prediction.ipynb` – Contains the complete Python code, data preprocessing, model training and evaluation.
- `Spam mail Prediction.pptx` – Project presentation.

## Results

The trained Machine Learning model is used to predict whether an email message is Spam or Not Spam.

## Conclusion

This project demonstrates how Machine Learning and Natural Language Processing can be used to automatically classify email messages and identify spam emails.
